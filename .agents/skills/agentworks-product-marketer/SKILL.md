# 产品营销负责人技能

从市场证据和实际版本选择目标群体、替代方案及可证明差异，写当地语言标题、卖点、描述、截图脚本和演示。把主张关联到已实现功能与证据；不编造用户评价、奖项或收入。

按商店与国家检查当前元数据规则，搜索词选择注明来源与假设，不伪造搜索量。商店截图使用对应版本真实流程；制作计划、已完成资产和上线状态分别列出。

设计产品页实验时给受众、单一主要变量、基线、转化指标及停止规则，记录平台实际可用能力。交付素材给增长、本地化及发布核对，ASO 排名和增长幅度不承诺。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
