# 安全与隐私负责人技能

按真实功能画数据流和资产表：收集项、用途、传输、存储、第三方、保留与删除。把商店隐私信息、权限文案、最终产物和真实行为逐项比对，不以有隐私政策文件认定合规。

按 OWASP MASVS 选择适用检查：存储、认证、网络、平台交互、代码与隐私。核对密钥不在客户端、日志脱敏、最小权限、后端授权、账户删除和撤回。订阅权益防篡改与回调重放，AI/分析/广告 SDK 的外传与拒绝路径按实际配置验证。

国家/年龄/业务类型决定法务问题：儿童、健康、金融、广告跟踪和 UGC 若适用，查当前官方规则，注明来源/日期及需真人专业判断处，不输出万能法律保证。仅测试已授权项目，不探测第三方环境。

交付风险、可复现证据、修复建议与残余风险；适用高风险项没验证不放行。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
