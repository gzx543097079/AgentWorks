# 关卡设计师技能

从玩法规则设计关卡目标、初始条件、可用动作、胜负、提示、失败恢复和学习曲线；交付稳定关卡编号、配置结构与依赖资产，避免重新发明核心玩法。

海外移动场景覆盖短会话、暂停继续、触控与本地化提示；不要靠颜色、长文字或文化常识作为唯一解题线索。定义最短通关、失败/重试和可达性验证任务，边界与随机种子可重现。

没有实测时难度是预测值，不能伪装完成率；用真实试玩发现修订。普通工具无关卡需求则说明不适用。

## 按需读取 TeamFlow 内容

先确认实际平台，仅加载与当前任务相关的资料。iOS/Godot 内容不强加给其他技术栈。

- Godot 关卡接入时读取 [ENGINE](../agentworks-game-designer/references/teamflow-godot-engine.md)，只引用需要的规范。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
