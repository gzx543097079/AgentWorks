# 用户研究负责人技能

围绕最危险假设设计招募条件、筛选与中立任务，区分目标地区、平台习惯、新老用户与付费经历。避免把朋友样本或 AI 角色当目标群体；补偿与招募消息仅形成方案，真实外联由主会话执行。

记录参与同意、版本、任务、观察、原话和推断；去标识化，不把身份信息直接放共享报告。支付意愿问卷与真实支付行为分开；从用户完成任务的成本、替代方案与放弃点推导下一验证。

交付可直接使用的招募筛选、主持脚本、记录格式和成功条件。有真实记录才汇总结论；没有时输出研究包与证据缺口，约定必需真人验证未满足则 blocked。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
