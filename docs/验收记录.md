# 桌面版验收记录

日期：2026-10-14（Asia/Shanghai）。版本：0.2.0。

当前目标：Codex 桌面端与 Claude 桌面端 Code 模式共用团队配置，使用原生子 Agent 协作，移除独立命令行运行路径。

## 已完成

- 已删除产品命令行入口、Codex／Claude 模型后端适配、模型子进程调度器及两份真实命令行调用脚本。
- 31 项自动化测试通过，包括两种桌面会话共用状态、依赖交接、只读批次、可写任务独占、重复领取拦截、过期 ticket 拒绝、交付格式及文件校验、中断恢复、失败重试、完整六阶段流程和备份恢复。
- 桌面交接测试在禁止启动外部进程的条件下完成状态保存和跨平台接续，确认内部模块不需要启动模型客户端。
- 模拟六阶段流程验证了状态和交接，不代表真实市场研究、产品开发或运营成效。
- 两份桌面技能通过 skill-creator 校验，共用角色、Codex 原生角色、Claude 原生角色和技能通过同步检查。
- 内部检查识别15个角色、6个工作流，生成配置没有漂移。
- 既有 first-opportunity 项目无需迁移即可读取，仍在 discovery 阶段，正式研究任务均未执行，尝试次数保持0。

## 尚未验证

- 尚未在 Claude 桌面端 Code 模式中完成真实原生子 Agent 的端到端交接；文件格式和内部交接逻辑检查不能替代桌面实测。
- 本轮在当前 Codex 桌面会话中验证了内部状态读取和本地模块，没有启动真实产品研究，也未进行新的原生多 Agent 产品任务。
- 未验证任何产品的真实需求、付费、留存或盈利，未执行生产发布、投放或对外消息。
- 未连接所有可选图像、浏览器、引擎及运营账号，未部署常驻服务。

## 历史验证的适用范围

旧版本曾通过30项测试和两个真实 Codex 命令行角色的交接检查。对应运行入口现已删除，这些历史结果不能用来宣称桌面原生协作已经实测。历史提交与本机验证日志仍保留，现有项目数据没有删除。

## 后续桌面验收方法

在目标桌面端打开同一份本地仓库，要求团队新建一个专门的测试项目，用两名原生角色处理本地简报并交接，再重新打开会话检查状态。测试项目与实际产品分开，使用真实交付和独立上下文，不把模拟记录写成真人反馈。

日常使用见 [桌面使用指南](使用指南.md)，维护与状态接口见 [桌面内部接口](桌面内部接口.md)。
