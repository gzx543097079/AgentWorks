# 桌面版验收记录

日期：2026-10-14（Asia/Shanghai）。内部模块版本：0.2.0；团队配置版本：2。

当前目标：Codex 桌面端与 Claude 桌面端 Code 模式共用 27 个角色与六阶段流程，使用原生子 Agent 协作，保留既有项目进度。

## 已完成

- 已删除产品命令行入口、Codex／Claude 模型后端适配、模型子进程调度器及两份真实命令行调用脚本。
- 34 项自动化测试通过，包括两种桌面会话共用状态、依赖交接、只读批次、可写任务独占、重复领取拦截、过期 ticket 拒绝、交付格式及文件校验、中断恢复、失败重试、完整六阶段流程和备份恢复。
- 新增回归检查：美术与音频写入任务独占且阻止另一桌面重复分发；代码复核待修改或安全复核阻塞时，最终 QA 和上线阶段均不可放行。完整桌面交接夹具覆盖全部 27 个角色。
- 桌面交接测试在禁止启动外部进程的条件下完成状态保存和跨平台接续，确认内部模块不需要启动模型客户端。
- 模拟六阶段流程验证了状态和交接，不代表真实市场研究、产品开发或运营成效。
- 两份桌面技能沿用此前通过 skill-creator 校验的内容；本次共用角色、Codex 原生角色、Claude 原生角色和技能通过同步检查。
- 内部检查识别 27 个角色、6 个工作流、54 项任务；通用角色卡与两平台各 27 份角色配置一致。四个可写角色为 UI、开发、美术和音频，其余只读。
- 只读检查确认既有 first-opportunity 项目仍保留原 discovery 快照的 5 个待执行任务，尝试次数为0。本次未修改其进度；新规划阶段使用新版配置。

## 尚未验证

- 尚未在 Claude 桌面端 Code 模式中完成真实原生子 Agent 的端到端交接；文件格式和内部交接逻辑检查不能替代桌面实测。
- 本轮在当前 Codex 桌面会话中验证了配置、已有状态读取和本地模块，没有启动真实产品研究，也未进行新的原生多 Agent 产品任务。新增角色的业务质量及桌面实际加载仍需实际任务验证。
- 未验证任何产品的真实需求、付费、留存或盈利，未执行生产发布、投放或对外消息。
- 未连接所有可选图像、浏览器、引擎及运营账号，未部署常驻服务。

## 历史验证的适用范围

旧版本曾通过30项测试和两个真实 Codex 命令行角色的交接检查。对应运行入口现已删除，这些历史结果不能用来宣称桌面原生协作已经实测。历史提交与本机验证日志仍保留，现有项目数据没有删除。

## 后续桌面验收方法

在目标桌面端打开同一份本地仓库，要求团队新建一个专门的测试项目，用两名原生角色处理本地简报并交接，再重新打开会话检查状态。测试项目与实际产品分开，使用真实交付和独立上下文，不把模拟记录写成真人反馈。

日常使用见 [桌面使用指南](使用指南.md)，维护与状态接口见 [桌面内部接口](桌面内部接口.md)。
