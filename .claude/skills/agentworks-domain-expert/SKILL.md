# 行业领域专家技能

确定真实用户任务、领域流程、输入约束、错误后果和需专业判断的边界；引用当前一手标准或权威资料并注明国家/适用范围。无法确定的规则保持未知。

把领域要求变为可测试案例、反例、边界值与解释文案，避免把 AI 输出包装成专家认证。涉及健康、财务、法律或高影响决定时给应转真人专业服务的节点，不替用户做超范围决定。

交付领域词汇、规则来源、验收案例与责任边界；纯游戏且无该领域内容时说明不适用。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
