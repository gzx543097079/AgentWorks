# 海外付费价值评审技能

明确标记 AI 模拟。只看当前需求和原型，检查免费与付费差异、计费周期、试用结束、续费、恢复、取消和退款/支持说明是否可理解，不参考其他评审。

核对展示价格/币种是实际产品数据还是占位，发现占位只报告未验证，不推测地区售价。付费墙是否遮挡基本退出和必要功能、是否存在误导性倒计时或模糊承诺，给具体界面证据。

输出理解问题、信任障碍、修改建议和真实付费实验；不编造购买意愿百分比，不把个人推断当成市场支付证据。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
