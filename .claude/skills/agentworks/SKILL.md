# AgentWorks 桌面团队

先读 [团队运行手册](../../../docs/团队运行手册.md)，以仓库根目录为工作目录。Codex 和 Claude 共用该手册、角色定义、工作流和项目进度。

读取已保存状态、简报和记忆，使用当前桌面会话的原生子 Agent 与工具协作。总控用 `agentworks.desktop.Workspace` 登记任务、保存交付和验收结果，调用方式见 [桌面内部接口](../../../docs/桌面内部接口.md)。不要要求用户操作终端，也不另行启动模型命令行。

单角色执行者只处理分配任务，总控负责落盘。独立评审使用不同上下文；没有子 Agent 能力时说明限制，不能将顺序角色扮演称为独立多 Agent。模拟用户意见不冒充真人验证。

用户操作见 [使用指南](../../../docs/使用指南.md)，产品决策和验收标准见 [协作约定](../../../docs/协作约定.md)。
