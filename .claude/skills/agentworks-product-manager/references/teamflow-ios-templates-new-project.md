## 工程身份

- 产品名称 / 工程名称：采用用户已给出的名称；内部工程名可据此推导
- Bundle ID：采用已明确的组织与 App 身份；涉及签名或平台注册而身份未知时询问，不把示例值当成批准
- App 版本 / build：无既有约定时使用 `1.0.0` / `1`
- 工程目录：当前产品工作区 `app/` 下，沿用已有工程布局

## 技术起点

- 语言：无既有约定时使用 Swift
- UI：无既有约定时使用 SwiftUI App 生命周期；需要 SwiftUI 无法满足的能力时在对应页面嵌入 UIKit 并记录原因，团队或需求明确选择 UIKit 时沿用
- 架构：沿用既有决定，否则根据首版范围采用最小方案；关键取舍无法推断时才询问
- 最低系统：沿用产品覆盖范围；无约定时取当前 Xcode 支持的最低部署版本与所需 API（如 Observation 需 iOS 17）中较高者，写入卡片决策
- 依赖管理：默认 Swift Package Manager；保留既有项目约定
- 首个 Target / Scheme：沿用已有配置或根据工程名生成
- 当前开发与演示语言：采用需求与目标用户已明确的语言；影响首版范围且无法推断时询问
