# iOS 键盘与输入

> 来源：TeamFlow `teamflow-v1.0.0`，提交 `e2088f01b7834ca1cf7217004309fe0cb22ee3bc`，原文件 `.agents/skills/iOS/references/standards/ui-keyboard.md`。保留专业规范并调整资源链接；文中的 TeamFlow 专属命令/路径仅适用于已安装原工具的业务工程，不能据此声称当前仓库已安装它们。 用户当前目标、平台和既有授权优先；版本号及商店/地区规则在实际执行时重新核对。

键盘规则核对日期：2026-09-28。通用 UI 规则见 [UI 规范](teamflow-ios-standards-ui.md)。

## 适用范围

【团队默认】本次新增或修改输入框、搜索、表单、多行编辑、输入弹窗或底部输入栏时，核对实际涉及的以下规则。普通非输入页面不触发；沿用已有适用实现，不默认引入全局键盘管理器或迁移全 App。

## 布局与焦点

- 当前输入框、光标及相关错误提示保持可见；空间不足时允许滚动，并在焦点切换后按需滚动到可视区域。多行编辑优先保证光标附近可见，不强求整个编辑器同时显示。
- 根据当前窗口中的实际遮挡适配布局，不写死键盘高度、不用全屏尺寸直接推算。键盘弹出、收起、输入法和候选栏高度变化时同步布局；支持的旋转、分屏和窗口缩放同样处理。
- 同一区域只采用一套避让机制，避免系统安全区、约束和手工 contentInset 重复补偿。收起时恢复本次调整的间距和滚动指示器，不无条件把原有 inset 或滚动位置清零。
- 焦点有明确所有者。仅在用户开始输入或明确的输入任务入口自动聚焦；在视图已进入当前窗口、转场合适阶段执行，不靠固定延迟，也不在每次渲染或刷新时重新抢焦点。
- 多字段表单按可见、可编辑字段的业务顺序切换“下一项”；最后一项使用合适的“完成”“搜索”或提交动作。列表中的输入使用稳定身份，刷新不能丢失文本、光标位置或焦点。

## 收起、提交与页面退出

- 普通表单提供空白区域点击及适用的滚动收起行为；编辑器或聊天输入按产品场景选择。手势不能吞掉按钮点击、列表选择、文本选择和辅助功能操作，不添加覆盖全屏的透明拦截层。
- 数字或金额键盘没有 Return 键时，提供可发现、可访问的收起入口，例如输入工具栏“完成”。工具栏文案遵守本地化规范。
- 软件 Return、外接键盘和按钮触发的同一业务动作共用校验与防重复提交逻辑。多行编辑的 Return 默认换行，发送单独提供；明确产品约定除外。
- 点击提交应在第一次点击时执行校验，不能只收起键盘而要求再点一次。校验失败保留内容，让首个错误字段及原因可见，按需聚焦；请求失败保留可重试的输入，提交成功后的收起或焦点保留按场景决定。
- 输入弹窗、Sheet、半屏表单在键盘弹出后可滚动，确认和取消入口始终可达。关闭或返回时结束该页面编辑，清理页面持有的监听与延迟聚焦任务；取消交互式返回时不清空内容或强行重置布局。
- 页面已离开、被关闭或不是当前活动输入场景时，异步回调不得再次唤起键盘；重新进入或前后台恢复按明确的页面状态恢复，不无条件自动聚焦。收起键盘本身不代表提交、取消或删除草稿。

## 输入法与设备边界

- 中文等输入法存在组合文本阶段；UIKit 核对 `markedTextRange`，自定义 SwiftUI 输入封装保留等效组合状态。组合未完成时不强制截断、格式化、替换文本或切换焦点，不把中间候选当最终值提交；确认组合文本后再按业务规则校验。
- 粘贴、替换、自动填充及语音输入同样经过输入规则；不能因选择了数字键盘就假定内容必为数字。长度限制按业务定义处理字符，避免截断 Emoji 或组合字符；金额格式尊重当前业务的地区规则。
- 支持 iPad 时覆盖停靠与浮动键盘，浮动键盘不按整屏底部高度整体上推。外接键盘即使没有软件键盘，焦点切换、提交和退出也必须可用；辅助工具栏仍可能造成遮挡。

## 实现选择

- UIKit（OC / Swift）：iOS 15+ 优先 `keyboardLayoutGuide`；浮动键盘按实际需求配置跟随及适应性约束，不假定默认跟随。工程确实支持更低系统时才增加键盘 frame 变化通知适配，转换到当前窗口/容器坐标计算遮挡，并同步系统动画；明确监听生命周期，避免跨窗口或重复响应。
- SwiftUI：优先使用系统键盘安全区避让、可滚动容器和 `FocusState`；按支持系统使用 `scrollDismissesKeyboard` 配置滚动收起。先核对 API 可用性，不为使用新 API 擅自提高部署目标；不在输入内容容器上无条件忽略键盘安全区，也不叠加手工高度补偿。

## 输入验收

涉及输入时，最低覆盖底部字段聚焦与可见性、下一项切换（多字段）、收起与再次弹出、首次点击提交、校验/请求失败保留内容（涉及时）、退出与再次进入。中文组合输入在支持中文输入的字段中验证；多行、数字键盘、输入弹窗、旋转、iPad 浮动/分屏及外接键盘按页面和支持范围补充。检查重复操作后没有累积间距、跳动、文本丢失或重复提交，普通无障碍核对收起/提交入口和焦点可达性。

将适用的可观察结果写入原需求卡并引用实际运行证据，不复制第二份键盘台账。UI 测试可覆盖主交互；模拟器或自动化未覆盖的输入法候选、浮动键盘和外接键盘场景保留未验证，使用相应实际环境补验。编译、静态规则检查或文档测试不能证明业务页面键盘行为通过。
