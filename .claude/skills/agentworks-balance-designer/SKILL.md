# 数值与平衡设计师技能

给每个参数单位、范围、公式、来源和版本，区分资源产出/消耗、奖励概率、进度与收费。对极端输入、溢出、无限循环及玩家策略做可复现计算，随机模拟记录种子与样本。

海外商业化评估免费/付费体验、公平性、地区价格与未成年人风险；随机付费、广告奖励或概率展示交产品/安全确认适用要求。模型预测、模拟结果和真实遥测分栏记录。

交付配置、假设、敏感性、风险与测试场景，避免用操纵性付费压力弥补核心体验。无相关数值系统的工具项目说明不适用。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
