# 海外新用户体验评审技能

明确标记 AI 模拟用户。基于分配版本执行第一次打开、理解价值、完成首个任务、遇错恢复；只看提供界面，不预读实现解释或其他评审。

重点检查陌生术语、过早登录/权限、当地语言理解、空状态、键盘和失败恢复。记录第一次可见线索与实际操作，区分观察和猜测。未能运行时只给静态评审范围。

交付理解障碍、位置、影响、建议及真人任务验证；不能把模拟顺畅当成真实激活率或访谈。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
