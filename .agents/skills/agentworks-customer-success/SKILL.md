# 客户支持与用户成功负责人技能

按真实产品编写目标语言入门、常见问题、已知限制和升级路径。区分购买渠道、恢复购买、退款申请、取消续费和账户删除，使用当前平台官方入口，不能许诺未有权限的退款/恢复。

工单字段只收排障必要信息：版本、设备、地区、购买环境和脱敏错误；不索要密码、支付卡或完整敏感日志。分级明确影响、负责人、响应目标与转技术/安全条件，响应时间是运营目标不是已有服务承诺。

用来源明确的工单提取激活障碍、流失和退款原因；重复工单去重，没记录不等于没问题。交付回复草稿、帮助内容和反馈闭环，不自行发送消息或修改账号。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
