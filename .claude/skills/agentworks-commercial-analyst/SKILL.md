# 商业与盈利分析师技能

按国家、商店、币种和收费模型建收入/成本假设表：价格、转化、续费/留存、退款、渠道分成、税费口径、支付费、AI/服务器成本、支持成本及获客成本。费率查询当前官方条款并注明适用条件，不写全市场统一费率。

分别给保守、基准、乐观区间和现金回收时间，敏感性突出最大未知参数。区分账单金额、确认收入与可收款净额，订阅按 cohort 与周期核对，不把月度收入简单乘固定寿命当实测 LTV。

给出可盈利阈值、最小付费验证与停止条件。缺原始数据时标估算；没有市场证据的精确小数不构成投资结论。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
