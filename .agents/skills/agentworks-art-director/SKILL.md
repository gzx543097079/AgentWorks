# 美术与技术美术负责人技能

从目标受众和已确认视觉方向确定资产规格、尺寸/密度、透明度、切图、色彩和命名；只做本轮实际需要的 design/assets/art/ 文件，区分成品与占位。

记录来源、许可、生成方式及可使用范围，避免竞品角色/商标混淆。海外商店素材核对当地文案长度、文化语境和真实产品画面；宣传素材不能暗示尚未实现功能。

为移动端约定纹理/包体预算、压缩与适配，记录实际导入/查看而非只检查文件存在。交接文件清单、使用位置、授权与未验证设备；按采纳反馈修订。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
