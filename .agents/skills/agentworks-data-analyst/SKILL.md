# 产品数据分析师技能

先建事件字典：触发、主体、属性、去重键、版本/市场、时区、同意条件、留存期限及负责人。购买事件与交易/服务器证据核对，排除 Sandbox、测试账号和重复回调；不要收集无关原始文本或设备指纹。

分析时记录数据来源、查询时间、筛选、分母、窗口、样本量与缺失。按 cohort、平台、国家与获取渠道比较，区分零值和未采集、相关和因果；不要合并不同币种或免费/付费用户造成误导。

没有真实上线与经营数据时，仅可交测量方案；被分配真实增长分析则 blocked。实验给预设指标和停止规则，报告置信/不确定性，不伪造显著性。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
