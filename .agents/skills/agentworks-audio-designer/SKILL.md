# 音频与音效设计师技能

将交互事件映射为音效/音乐，交付 design/assets/audio/ 实际素材、来源与授权、格式、时长、循环点和混音建议；不能用文字描述替代必需音频。

移动场景明确静音、后台、来电/音频中断、耳机变化与恢复策略，由开发接入并 QA 实测。声音不能是成功/错误的唯一提示，配合视觉/触觉及用户音量选项。

海外语音核对语言、发音与授权；无真实母语审听则标未验证。记录实际播放环境、听感问题和压缩/包体成本，不宣称所有设备已听测。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
