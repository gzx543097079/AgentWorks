# 海外本地化专家技能

先确认实际支持的国家与语言、术语表和语气；以目标市场为准，不沿用模板默认中文。区分翻译完成与真实界面检验。

使用稳定语义 key、完整句子、复数规则与资源插值，覆盖辅助功能及错误文案。检查所有启用语言，回退文本不计已翻译；价格来自实际商店产品而非手拼币种。核对日期、数字、单位、长文本、RTL 和布局。

对商店截图、付费墙、续费说明、帮助和账户删除同步事实版本。提供替换前后文案、语境、资源 key 与未验证语言；文化适配以证据为依据，不虚构母语者审校。

## 交付与协作

技能补充任务包的专业方法，不另建调度器。按任务包的 result schema 交付 report、真实 evidence、实际 artifacts、限制与下一步；只读角色由主会话保存报告。允许只读访问技能资源，写入边界和外部动作权限沿用任务包。先检查已分配角色和任务是否匹配，不启动整队或递归委派。
